# Historical notes

Audit and verification files from earlier stages of this project, kept for the record.

**They are not current.** Several describe behaviour that has since been found wrong and
changed — the analysis that replaced them is in `plans/README.md`, which records what was found,
what was decided and what was rejected, with evidence. Read that instead; these files are here so
that the reasoning of the time is not lost, not as documentation.
